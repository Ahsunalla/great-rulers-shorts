Privacy Policy

ShortsVideoes is a personal, non-commercial automation project. It uses the YouTube Data API solely to upload videos to a single YouTube channel that the developer owns and controls.

This application:

  • Does not collect, store, process, or share any personal data belonging to any third party or end user.
  • Does not have users other than the developer - it is not a public-facing service.
  • Only requests the youtube.upload permission scope, used exclusively to publish videos to the developer's own channel.

Questions: contact via the GitHub repository.
